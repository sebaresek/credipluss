# Crediplus Web 🏦

Sitio web oficial de **Crediplus**, una plataforma diseñada para simplificar la gestión de préstamos personales. Este repositorio contiene el frontend de la aplicación, enfocado en ofrecer una experiencia de usuario fluida, moderna y accesible.

## 🌐 Demo
Puedes visitar el sitio en vivo aquí: [www.crediplus.store](https://www.crediplus.store/)

## ✨ Características Principales

* **Diseño Moderno:** Interfaz basada en una estética *Elegant Dark* con acabados de *Glassmorphism* para una visualización profesional.
* **Diseño Responsivo:** Optimizado para funcionar perfectamente en dispositivos móviles, tablets y computadoras de escritorio.
* **Navegación Intuitiva:** Secciones claras para facilitar la conversión y la comprensión del servicio.
* **Optimización de Rendimiento:** Desarrollo ágil utilizando Vite para una carga instantánea.

## 🛠️ Stack Tecnológico

* **React.js** (JSX)
* **Tailwind CSS** (UI estilizada)
* **Vite** (Build tool)
* **Lucide Icons** (Iconografía minimalista)
